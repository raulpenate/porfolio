# Security Policy

If you believe you have found a security vulnerability, please report it privately.

## How to report

Email `dev.raulpenate@gmail.com` with:

- A description of the vulnerability
- Steps to reproduce (if applicable)
- Impact and affected versions/commit (if known)
- Any relevant logs or screenshots

## Expectations

We will acknowledge receipt and coordinate a private response process.
Please do not open public issues for vulnerabilities.
